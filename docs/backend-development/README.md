# Belboore Backend Development Program

This pack is the step-by-step execution system for building Belboore's backend with an AI coding agent.

## How to use

1. Copy this directory to `docs/backend-development/` in the Belboore monorepo.
2. Read `00_MASTER_ROADMAP.md`, `00_LOCKED_DECISIONS.md`, and `00_AGENT_OPERATING_RULES.md`.
3. Execute exactly one numbered step at a time.
4. Create the branch named in that step.
5. Give OpenCode `RUN_STEP_PROMPT.md` plus the current step file.
6. Do not merge until every acceptance criterion passes.
7. Require the agent to stop after the step and produce the standard handoff report.

This roadmap supersedes the old split `backend_dev_1_plan.md` / `backend_dev_2_plan.md` as an implementation plan. Those older documents remain useful historical input only.
